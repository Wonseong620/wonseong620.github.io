# wonseong620.github.io

Personal academic homepage of Wonseong Kim.

## Deploy (one-time)

1. Create a **public** repository named exactly `wonseong620.github.io` on GitHub
   (github.com/new, owner: Wonseong620).
2. From this folder, run:

   ```
   git remote add origin https://github.com/Wonseong620/wonseong620.github.io.git
   git push -u origin main
   ```

3. Wait ~1 minute. The site is live at **https://wonseong620.github.io**

## Update later

Edit `index.html`, then `git add -A && git commit -m "update" && git push`.
To add a CV, drop `cv.pdf` in this folder and link it as `<a href="cv.pdf">`.
